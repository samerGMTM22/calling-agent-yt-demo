# الخطوة 8: اجعل الوكيل خاصاً بك (الاسم، والصوت، واللغة، والشخصية)

تستطيع تغيير هوية وكيلك **دون أن تلمس أي كود**. هذه الصفحة تعرض كل خيار، ومكانه، وما لا يمكنك إيقافه (عن قصد).

## 8.1 كل ما يمكنك تغييره في لمحة

| ماذا | أين | متى يسري |
|---|---|---|
| اسم الوكيل | `AGENT_NAME` في `.env` | بعد إعادة تشغيل `npm run up` |
| اسمك أنت (يقول الوكيل: «الوكيل الذكي لـ *فلان*») | `OWNER_NAME` في `.env` | بعد إعادة التشغيل |
| لغة الافتتاح | `AGENT_LANGUAGE` في `.env` (`auto` أو `ar` أو `en`)، أو `--language` لكل مكالمة | بعد إعادة التشغيل / المكالمة التالية |
| الصوت | `OPENAI_VOICE` في `.env` | بعد إعادة التشغيل |
| الشخصية، والنبرة، واللهجة، ومعلومات عنك، وقواعد التعامل | **`persona.md`** (ملف نصي بسيط) | **من المكالمة التالية**، دون إعادة تشغيل |
| سبب هذه المكالمة | `--purpose "..."` مع `npm run call` | تلك المكالمة |
| معلومات خلفية يجب أن يعرفها الوكيل | `--context "..."` مع `npm run call` | تلك المكالمة |
| شيء يقوله أو يعرفه *أثناء* المكالمة | `npm run say` / `npm run note` | فوراً |
| طريقة إجابة العقل الاحتياطي (الوضعان `openai` و`anthropic`) | `BRAIN_SYSTEM` في `src/brain.js` | بعد إعادة التشغيل |
| للمتقدمين: التعليمات كاملة والجملة الأولى | `src/persona.js` | بعد إعادة التشغيل |

> يُقرأ ملف `.env` مرة واحدة عند تشغيل الخادم، لذا أوقف `npm run up` (بالضغط على Ctrl+C) وشغّله من جديد بعد تعديله. أما `persona.md` فيُقرأ من جديد في بداية كل مكالمة.

## 8.2 الاسم، والمالك، واللغة (`.env`)

```
AGENT_NAME=Sam
OWNER_NAME=Samer
AGENT_LANGUAGE=auto      # auto = start in English, mirror the caller | ar = start in Arabic | en = English
```

(`auto` = يبدأ بالإنجليزية ثم يتحدث بلغة المتصل، `ar` = يبدأ بالعربية، `en` = يبدأ بالإنجليزية.)

يبدأ الوكيل دائماً بجملة مثل: *«مرحباً، معك سام، الوكيل الذكي لسامر…»*.

**نصيحة بخصوص الاسم:** مع `VOICE_ENGINE=live` (الافتراضي) يعمل أي اسم، بما فيه «Claude». أما مع `VOICE_ENGINE=realtime` فنموذج OpenAI يرفض أن يسمّي نفسه باسم منتج ذكاء اصطناعي آخر، وقد يقول «ChatGPT» بدلاً منه؛ اختر اسماً محايداً مثل «سام» أو «نور».

## 8.3 الصوت (`OPENAI_VOICE`)

لكل محرّك قائمة أصوات خاصة به. الصوت الذي لا يدعمه المحرّك قد يمنع بدء المكالمة، لذا جرّب كل تغيير بمكالمة إلى نفسك.

| المحرّك | الأصوات | ملاحظات |
|---|---|---|
| `live` (GPT-Live، الافتراضي) | `marin` (الافتراضي)، إضافةً إلى `quartz` و`ripple` و`vesper` و`willow` و`stone` و`gleam` و`meridian` و`beacon` و`delta` و`cinder` | حالياً `marin` وحده مضمون لكل اللغات؛ الأصوات الأخرى مضبوطة للإنجليزية. للعربية، ابقَ على `marin`. |
| `realtime` (gpt-realtime-2.1) | `marin` و`cedar` و`alloy` و`ash` و`ballad` و`coral` و`echo` و`sage` و`shimmer` و`verse` | توصي OpenAI بـ `marin` و`cedar` للجودة. |

قوائم الأصوات تتغير؛ المرجع الرسمي هو أدلة OpenAI: [Live conversations](https://developers.openai.com/api/docs/guides/live-conversations) و[Realtime conversations](https://developers.openai.com/api/docs/guides/realtime-conversations).

## 8.4 الشخصية وقواعد التعامل (`persona.md`)

هذه أسهل طريقة لتحديد *كيف* يتكلم الوكيل و*ماذا* يعرف عنك.

1. انسخ القالب (داخل مجلد المشروع):

   ```bash
   cp persona.example.md persona.md
   ```

   على Windows (Command Prompt): `copy persona.example.md persona.md`

2. افتح `persona.md` في أي محرر نصوص (TextEdit أو Notepad أو VS Code) واكتب جملاً بسيطة، بالعربية أو بالإنجليزية. مثلاً:

   ```markdown
   ## الشخصية
   - ودود ومهني. لا بأس بقليل من المرح.

   ## أسلوب الكلام
   - مع المتحدثين بالعربية، استخدم لهجة خليجية ودودة.
   - اجعل الإجابات قصيرة: جملة أو جملتان.

   ## عنّي
   - أصنع فيديوهات عن الذكاء الاصطناعي للعرب على يوتيوب.
   - أفضل وقت للتواصل معي: أيام العمل من 10:00 إلى 18:00 بتوقيت دبي.

   ## قواعد التعامل
   - إذا طلب أحد موعداً، خذ اسمه والموضوع ووقتين مناسبين، وقل إنني سأؤكد برسالة.
   - لا تؤكد أبداً مكاني أو خطط سفري.
   ```

3. احفظه. **المكالمة التالية** ستستخدمه. الأمر `npm run doctor` وأسطر بدء تشغيل الخادم تُظهر هل وُجد الملف أم لا.

معلومات مهمة:

- **ملف `persona.md` يبقى على جهازك.** git يتجاهله، فلا يُرفع إلى GitHub أبداً. أما `persona.example.md` فهو القالب المشترك.
- **اعتبر أن أي شيء فيه قد يسمعه متصل.** الوكيل مُوجَّه بألا يكشف تعليماته، لكن نماذج الذكاء الاصطناعي يمكن إقناعها أحياناً. لا تضع فيه كلمات مرور، ولا أرقام بطاقات، ولا عنوان منزلك، ولا أي شيء تمانع أن يُقال بصوت عالٍ.
- **القصير المحدد أفضل من الطويل المبهم.** «أجب بجملة واحدة ثم اطرح سؤالاً» أفضل من «كن موجزاً وجذاباً». صفحة واحدة تكفي (يُقتطع الملف عند 8,000 حرف).
- **العربية والإنجليزية تعملان معاً.** اكتب القواعد باللغة التي تفكر بها.
- الأسطر داخل `<!-- ... -->` ملاحظات لك أنت؛ الوكيل لا يراها أبداً.
- تريد اسماً آخر للملف أو عدة شخصيات؟ اضبط `PERSONA_FILE=personas/sales.md` في `.env` (أي مسار؛ ثم أعد التشغيل).

## 8.5 تعليمات لمكالمة واحدة (`--purpose` و`--context` و`--language`)

استخدمها عندما يتعلق التغيير **بمكالمة واحدة**، لا بشخصية الوكيل:

```bash
npm run call -- --purpose "Remind Samer about the 4pm recording" \
                --context "The studio booking is confirmed; bring the blue mic" \
                --language ar
```

- `--purpose` يُقال بصوت عالٍ مباشرةً بعد التعريف بالنفس.
- `--context` معلومات خلفية يستخدمها الوكيل ولا يقرؤها بصوت عالٍ.
- أثناء المكالمة: `npm run note -- <callId> "..."` يضيف سياقاً صامتاً، و`npm run say -- <callId> "..."` يجعل الوكيل يقول شيئاً فوراً.

(يمكنك كتابة `--purpose` و`--context` بالعربية أيضاً.)

## 8.6 ما الذي يتلقاه الوكيل فعلاً (ترتيب التعليمات)

في كل مكالمة، يبني `src/persona.js` التعليمات بهذا الترتيب:

1. **من أنت:** الاسم، والمالك، و«أنت ذكاء اصطناعي».
2. **ملف `persona.md`** الخاص بك (إن وُجد).
3. **كيف تتحدث على الهاتف:** أدوار قصيرة، وقاعدة اللغة.
4. **العمل مع العقل:** متى يُحيل الأسئلة، وكيف تنتهي المكالمة.
5. **هذه المكالمة:** الاتجاه، ومن على الخط، والغرض والسياق.
6. **القواعد غير القابلة للتفاوض:** الإفصاح بأنه ذكاء اصطناعي، وقواعد الأمان. تأتي **في النهاية** وتتغلب صراحةً على كل ما سبقها، بما في ذلك ملف شخصيتك.

الجملة الأولى التي ينطقها الوكيل تُضبط بشكل منفصل عبر الدالة `greetingInstruction()` في الملف نفسه.

## 8.7 ما لا يمكنك إيقافه (ولماذا)

لا يستطيع `persona.md` إلغاء هذه القواعد، وإن عدّلت `src/persona.js` بنفسك فنرجو أن تُبقي عليها:

- **الإفصاح بأنه ذكاء اصطناعي:** التحية الأولى تقول إنه وكيل ذكاء اصطناعي يعمل نيابةً عنك، ولا يدّعي أبداً أنه إنسان. دول كثيرة تشترط ذلك في المكالمات الصوتية بالذكاء الاصطناعي (في الولايات المتحدة تطبّق هيئة FCC قواعد الموافقة على المكالمات الآلية على الأصوات المولّدة بالذكاء الاصطناعي).
- **قواعد الأمان:** يرفض كلمات المرور، والرموز لمرة واحدة، وأرقام البطاقات والهويات؛ ولا يوافق أبداً على أي دفع؛ ولا يشارك تفاصيلك الخاصة إلا إذا قدّمها العقل؛ ويحترم طلب «لا تتصل بي مجدداً»؛ ويوجّه إلى أرقام الطوارئ.

انظر [الأمان والامتثال](05-security-and-compliance.md) للصورة الكاملة.

## 8.8 للمتقدمين: تعديل `src/persona.js`

إن كنت مرتاحاً مع JavaScript (أو اطلب ذلك من وكيلك الذكي):

| الدالة | ما تتحكم فيه |
|---|---|
| `buildInstructions(call)` | التعليمات الكاملة لكل مكالمة (الأقسام المذكورة في 8.6). |
| `greetingInstruction(call)` | الجملة الأولى، في الحالات الأربع: أنت تتصل به، شخص آخر يتصل به، هو يتصل بك، هو يتصل بشخص آخر. |
| `languageRule(lang)` | معنى `auto` و`ar` و`en`. غيّر اللهجة العربية من هنا. |

بعد التعديل، شغّل `npm run check` (فحص الصياغة) وأعد تشغيل `npm run up`. ثم اتصل بنفسك لتسمع النتيجة.

## 8.9 اطلب ذلك من وكيلك الذكي

يمكنك وصف التغيير بكلمات بسيطة، ودع وكيلك يعدّل الملف الصحيح. مثلاً:

> «اقرأ docs/ar/08-customize-persona.md. ثم أنشئ persona.md بحيث يكون وكيلي الهاتفي ودوداً ورسمياً، ويتحدث بلهجة خليجية مع المتحدثين بالعربية، ويعرف أنني أدير قناة يوتيوب عن الذكاء الاصطناعي، ويستقبل طلبات المواعيد دون أن يؤكدها. لا تغيّر الإفصاح بأنه ذكاء اصطناعي ولا قواعد الأمان. ثم أخبرني كيف أجرّبه.»
