# حلّ المشكلات

ابدأ دائماً بالأمر `npm run doctor`. فهو يفحص كل خطوة ويطبع طريقة الإصلاح.

| العَرَض | السبب المرجّح ← الحل |
|---|---|
| `accountSid must start with AC` | القيمة في `.env` تحتوي على علامات اقتباس أو فواصل، أو أنها من الحقل الخطأ. الصق `AC…` فقط، دون علامات اقتباس. |
| Twilio `20003` / `401` | زوج SID والسرّ الخاص بمفتاح API خاطئ، أو أن المفتاح حُذف. أنشئ مفتاحاً جديداً من نوع **Standard** (قياسي). |
| Twilio `21215` / «geo permission» | دولة الرقم المطلوب غير مُفعّلة: Voice ← Settings ← **Geo permissions** (أذونات الدول). |
| Twilio `21219` (حساب تجريبي) | الحسابات التجريبية لا تستطيع الاتصال إلا بـ **Verified Caller IDs** (معرّفات المتصل الموثّقة). وثّق الرقم أو رقِّ الحساب. |
| رسالة «This is a trial account…» (هذا حساب تجريبي…) | أمر طبيعي في الحساب التجريبي. اضغط أي زر، أو رقِّ الحساب. |
| المكالمة تتصل، ثم صمت، ثم تنقطع | لا يمكن الوصول إلى الخادم: هل الأمر `npm run up` يعمل؟ هل يعرض `npm run status` رابطاً عاماً؟ هل رابط webhook للرقم هو رابط ngrok **الحالي** (`npm run twilio:connect`)؟ |
| مكالمتك أنت تُرفض | يجب أن يطابق رقمك في `.env` تماماً صيغة E.164 (`+9715…`، دون مسافات ودون أصفار في البداية). تحقق باستخدام `npm run status`. وإن كان رقمك يستخدم بوابة Twilio Function، فأضف الرقم هناك أيضاً. |
| `No public URL` (لا يوجد رابط عام) | شغّل ngrok (الأمر `npm run up` يفعل ذلك) أو اضبط `PUBLIC_URL`. |
| ngrok `ERR_NGROK_4018` | أضف رمز authtoken الخاص بك: `ngrok config add-authtoken …` |
| OpenAI `401` | المفتاح خاطئ أو محذوف. أنشئ مفتاحاً جديداً. |
| نموذج OpenAI «not found» (غير موجود) / لا صلاحية وصول | أضف رصيداً، وانتظر بضع دقائق، أو وثّق مؤسستك (Settings ← Organization). |
| الوكيل لا يجيب عن الأسئلة المُحالة | في وضع `BRAIN_MODE=agent` يجب أن يشغّل أحدٌ ما `npm run watch` و`npm run answer`. وإلا فسيجيب العقل الاحتياطي بعد `BRAIN_TIMEOUT_SECONDS`. |
| العقل يجيب ببطء | قلّل قيمة `BRAIN_TIMEOUT_SECONDS`، أو استخدم `BRAIN_MODE=openai` مع نموذج أسرع في `OPENAI_BRAIN_MODEL`. |
| الوكيل يرد بلغة خاطئة | اضبط `AGENT_LANGUAGE=ar` (أو `en`)، أو مرّر `--language ar` إلى `npm run call`. |
| في `VOICE_ENGINE=realtime` يسمّي الوكيل نفسه «ChatGPT» | نموذج realtime من OpenAI يتجنب استخدام اسم منتج ذكاء اصطناعي آخر (مثل «Claude»). استخدم اسماً محايداً في `AGENT_NAME` مثل «Sam»، أو ابقَ على `VOICE_ENGINE=live`. |
| الصوت متقطع | تحقق من سرعة الرفع في اتصالك بالإنترنت؛ وأغلق التطبيقات الثقيلة؛ وأبقِ الحاسوب المحمول مستيقظاً (دون سكون). |

## السجلات

تطبع نافذة طرفية الخادم سطراً واحداً لكل حدث مهم (مع إخفاء جزء من أرقام الهواتف، ودون أي أسرار). والأمر `npm run watch` يعرض بثّ الأحداث المباشر كاملاً. أما المكالمات المنتهية فتجدها في `calls/*.json`.
