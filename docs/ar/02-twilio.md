# الخطوة 2: حساب Twilio ورقم الهاتف ومفتاح API

تمنح Twilio وكيلك رقم هاتف حقيقياً وتوصل المكالمات إلى حاسوبك. ستحتاج إلى:

| الاسم في `.env` | شكله | من أين تحصل عليه |
|---|---|---|
| `TWILIO_ACCOUNT_SID` | `AC` + 32 حرفاً | الصفحة الرئيسية للوحة التحكم (Console) |
| `TWILIO_API_KEY_SID` | `SK` + 32 حرفاً | مفتاح API الذي تُنشئه |
| `TWILIO_API_KEY_SECRET` | 32 حرفاً | يظهر مرة واحدة عند إنشاء المفتاح |
| `TWILIO_PHONE_NUMBER` | `+15551234567` | الرقم الذي تشتريه |

> ⏱ نحو 15 إلى 20 دقيقة. 💳 تحتاج إلى بطاقة لترقية الحساب (وهذا مُستحسن). القوائم تتغير أحياناً: ابحث عن الكلمات نفسها في مكان قريب.

## 2.1 أنشئ الحساب

1. افتح **https://www.twilio.com/try-twilio**.
2. سجّل ببريدك الإلكتروني (أو بحساب Google)، واختر كلمة مرور قوية.
3. **تحقّق من بريدك الإلكتروني**: افتح رسالة Twilio وانقر على الرابط.
4. **تحقّق من رقم هاتفك**: سترسل Twilio رمزاً برسالة نصية SMS؛ اكتبه. يصبح هذا الرقم أول «معرّف متصل موثَّق» (verified caller ID) لديك، وهذا مهم في الحسابات التجريبية.
5. أجب عن أسئلة التعريف القصيرة. أي إجابات تصلح؛ مثلاً: *Voice* ← *With code* ← *Node.js*.
6. ستصل إلى **Twilio Console** (لوحة تحكم Twilio)، ومعك بعض الرصيد التجريبي المجاني.

## 2.2 رقِّ الحساب (مُستحسن)

الحسابات التجريبية تكفي لأول تجربة، لكن:
- لا تستطيع الاتصال إلا بالأرقام **الموثَّقة**،
- وكل مكالمة تبدأ برسالة «This is a trial account…» (هذا حساب تجريبي…) وتطلب منك الضغط على زر.

لإزالة هذه القيود:
1. في لوحة التحكم، انقر على **Upgrade** (ترقية) في الشريط العلوي، أو اذهب إلى **Admin → Account billing** (الإدارة ← فوترة الحساب).
2. أضف بطاقتك ورصيداً مبدئياً (مثلاً **20 دولاراً**).

💡 **دليل التكلفة:** الرقم الأمريكي يكلّف نحو 1.15 دولار شهرياً. والمكالمات تكلّف سنتات لكل دقيقة (وأكثر للهواتف المحمولة الدولية). راجع https://www.twilio.com/en-us/voice/pricing.

## 2.3 اشترِ رقم هاتف

1. من القائمة اليسرى: **Phone Numbers → Manage → Buy a number** (أرقام الهاتف ← الإدارة ← شراء رقم).
   (إن لم تجدها، فانقر أولاً على **Explore products → Phone Numbers** (استكشاف المنتجات ← أرقام الهاتف).)
2. اختر **الدولة**. الرقم من **United States** (الولايات المتحدة) هو الأسرع (دون أوراق). دول كثيرة أخرى تتطلب حزمة مستندات تنظيمية (وثائق هوية/عنوان).
3. تحت **Capabilities** (الإمكانات)، ضع علامة على **Voice** (الصوت).
4. انقر على **Search** (بحث)، واختر رقماً، ثم انقر على **Buy** (شراء) ← **Buy +1 …**.
5. انسخ الرقم **بصيغة E.164** (مع `+` ورمز الدولة، دون مسافات)، مثلاً `+15551234567`.

## 2.4 اعثر على Account SID (معرّف الحساب)

1. اذهب إلى الصفحة الرئيسية للوحة التحكم: https://console.twilio.com
2. انزل إلى مربع **Account Info** (معلومات الحساب).
3. انسخ **Account SID** (يبدأ بـ `AC`).

## 2.5 أنشئ مفتاح API (بدلاً من استخدام Auth Token الرئيسي)

يمكن إلغاء مفتاح API وحده دون المساس ببقية حسابك، وهذا يجعله أكثر أماناً.

1. أعلى اليمين، انقر على **اسم حسابك ← API keys & tokens** (مفاتيح ورموز API).
   (أو: **Admin → Account management → API keys & tokens** (الإدارة ← إدارة الحساب ← مفاتيح ورموز API).)
2. انقر على **Create API key** (إنشاء مفتاح API).
3. املأ الحقول:
   - **Friendly name** (اسم مألوف): `calling-agent`
   - **Region** (المنطقة): United States (US1) (الخيار الافتراضي)
   - **Key type** (نوع المفتاح): **Standard** (قياسي)
4. انقر على **Create** (إنشاء).
5. انسخ **SID** (يبدأ بـ `SK`) و**Secret** (السر). ⚠️ **السر يظهر مرة واحدة فقط.** ضع علامة على «Got it!» وانقر على **Done** (تم) فقط بعد أن تحفظ القيمتين كلتيهما.

## 2.6 ضع القيم في `.env`

```
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_API_KEY_SID=SKxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_API_KEY_SECRET=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_PHONE_NUMBER=+15551234567
```

دون علامات اقتباس، ودون فواصل، ودون مسافات. (التطبيق يتسامح مع علامات الاقتباس الزائدة، لكن الكتابة النظيفة أفضل.)

### اختياري: Auth Token للتحقق من توقيعات الـ webhook

في صفحة **API keys & tokens** نفسها، تحت **Live credentials** (بيانات الاعتماد الفعلية)، ستجد **Auth Token** (رمز المصادقة). إن وضعته في `TWILIO_AUTH_TOKEN`، فسيتحقق الخادم من التوقيع المُشفَّر الذي ترسله Twilio مع كل طلب webhook. ومن دونه، يتحقق الخادم من كل مكالمة عبر واجهة Twilio API بدلاً من ذلك، وهي طريقة آمنة أيضاً، لكنها أبطأ قليلاً. تعامل مع Auth Token كأنه كلمة مرور رئيسية.

## 2.7 اسمح بالدول التي ستتصل بها (Geo permissions، أذونات الدول)

تحظر Twilio افتراضياً الاتصال بمعظم الدول (لمكافحة الاحتيال).

1. اذهب إلى **Voice → Settings → Geo permissions** (الصوت ← الإعدادات ← أذونات الدول).
   (أو افتح https://console.twilio.com/us1/develop/voice/settings/geo-permissions.)
2. ضع علامة على الدول التي تحتاجها **فقط** (مثلاً الإمارات العربية المتحدة، السعودية، مصر، الأردن…).
3. انقر على **Save** (حفظ).

اترك كل ما عدا ذلك دون علامة. هذه من أفضل وسائل حمايتك من احتيال المكالمات المدفوعة (toll fraud).

## 2.8 للحسابات التجريبية فقط: وثّق الأرقام التي ستتصل بها

**Phone Numbers → Manage → Verified Caller IDs → Add a new Caller ID** (أرقام الهاتف ← الإدارة ← معرّفات المتصل الموثّقة ← إضافة معرّف جديد) ← أدخل الرقم ← استلم الرمز ← أكّد.

## 2.9 أضف رقمك الشخصي إلى `.env`

```
OWNER_PHONE_NUMBER=+9715XXXXXXXX
```

هذا هو **هاتفك المحمول الشخصي**. افتراضياً، هو الرقم **الوحيد** المسموح له بالاتصال بالوكيل، والرقم الوحيد المسموح للوكيل بالاتصال به. راجع [الأمان](05-security-and-compliance.md).

## 🔐 حافظ على سرية هذه القيم

`TWILIO_API_KEY_SECRET` و`TWILIO_AUTH_TOKEN` هما بمثابة كلمتَي مرور لفاتورة هاتفك. لا تشاركهما أبداً، ولا ترفعهما إلى المستودع أبداً، ولا تعرضهما على الشاشة أبداً. إن تسرّب أحدهما: **API keys & tokens ← احذف المفتاح** (أو بدّل Auth Token) فوراً.
