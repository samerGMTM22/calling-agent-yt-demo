# الخطوة 1: حساب OpenAI والفوترة ومفتاح API

تحتاج إلى قيمة واحدة من OpenAI: **`OPENAI_API_KEY`**. هذا المفتاح هو ما يُدفع منه ثمن الصوت (GPT-Live)، ومن العقل الاحتياطي أيضاً إن استخدمته.

> ⏱ نحو 10 دقائق. 💳 تحتاج إلى بطاقة خصم أو بطاقة ائتمان. المواقع تغيّر قوائمها من حين لآخر: إن تغيّر مكان زر ما، فابحث عن الكلمات نفسها في مكان قريب.

## 1.1 أنشئ الحساب

1. افتح **https://platform.openai.com/signup**.
   (هذه هي *منصة المطوّرين*. اشتراك ChatGPT Plus منفصل عنها و**لا** يتضمن رصيداً لاستخدام الـ API.)
2. سجّل باستخدام بريدك الإلكتروني، أو حساب Google أو Microsoft أو Apple.
3. إن سجّلت بالبريد الإلكتروني: افتح رسالة التحقق وانقر على الرابط.
4. أدخل اسمك وتاريخ ميلادك عند الطلب. ستُنشأ لك مؤسسة (organization) تلقائياً.

## 1.2 أضف وسيلة دفع ورصيداً

الـ API يعمل بنظام الدفع حسب الاستخدام: تشتري رصيداً مسبقاً، والمكالمات تستهلك منه.

1. انقر على **أيقونة الترس ⚙️ (Settings)** (الإعدادات) أعلى اليمين.
2. من القائمة اليسرى، افتح **Billing** (الفوترة).
3. انقر على **Add payment details** (إضافة بيانات الدفع) ← اختر **Individual** (فرد) (أو **Company** (شركة)) ← أدخل بيانات بطاقتك ← **Continue** (متابعة).
4. اختر مبلغ الرصيد. **10 دولارات** تكفي لساعات طويلة من التجربة. الحدّ الأدنى 5 دولارات.
5. اترك **auto-recharge** (إعادة الشحن التلقائي) **مُطفأً** ما دمت تتعلّم. بهذا لا يمكنك أن تصرف أكثر مما دفعته مسبقاً.
6. خطوة اختيارية لكنها ذكية: **Settings → Limits** (الإعدادات ← الحدود) ← اضبط تنبيهاً لميزانية شهرية.

💡 **دليل التكلفة:** يكلّف GPT-Live نحو **0.05 دولار لكل دقيقة** مكالمة (والحساب بالثانية). أما نموذج العقل الاحتياطي فيكلّف بضعة سنتات لكل سؤال على الأكثر.

## 1.3 أنشئ مفتاح API

1. اذهب إلى **https://platform.openai.com/api-keys** (أو Settings ← **API keys** (مفاتيح API)).
2. انقر على **+ Create new secret key** (إنشاء مفتاح سري جديد).
3. املأ الحقول:
   - **Owned by** (المالك): You
   - **Name** (الاسم): `calling-agent` (أي اسم يذكّرك بالغرض منه)
   - **Project** (المشروع): Default project
   - **Permissions** (الصلاحيات): All
4. انقر على **Create secret key** (إنشاء المفتاح السري).
5. **انسخ المفتاح الآن.** يبدأ بـ `sk-` ويظهر **مرة واحدة فقط**. إن أضعته، فاحذفه وأنشئ مفتاحاً جديداً.

## 1.4 ضعه في ملف `.env`

داخل مجلد المشروع:

```bash
cp .env.example .env
```

افتح `.env` بأي محرّر نصوص، والصق المفتاح بعد علامة `=`، **دون علامات اقتباس**:

```
OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxxxxxx
```

## 1.5 إذا ظهرت رسالة أن النموذج «غير متاح» (not available)

الأمر `npm run doctor` (في الخطوة 4) يتحقق من أن مفتاحك يستطيع استخدام `gpt-live-1`. إن لم يستطع:

- تأكد أنك أضفت رصيداً (الفقرة 1.2). الحسابات المجانية لا تستطيع استخدام نماذج الصوت الفوري (realtime).
- بعض النماذج الأحدث تتطلب **التحقق من المؤسسة**: Settings ← **Organization → General → Verify Organization** (المؤسسة ← عام ← التحقق من المؤسسة)، ثم اتبع خطوات التحقق من الهوية. يستغرق ذلك عادةً دقائق.
- الحسابات الجديدة تحتاج أحياناً إلى بضع دقائق بعد أول عملية دفع.

## 🔐 حافظ على سرية المفتاح

- لا تلصقه أبداً في محادثة، أو فيديو، أو لقطة شاشة، أو بلاغ (issue) على GitHub، أو داخل الكود.
- مكانه الوحيد هو ملف `.env`، وهذا الملف يتجاهله git.
- إن تسرّب يوماً ما، فاذهب إلى **API keys**، واحذفه (**Delete**)، وأنشئ مفتاحاً جديداً. هذا يوقف أي إساءة استخدام فوراً.
