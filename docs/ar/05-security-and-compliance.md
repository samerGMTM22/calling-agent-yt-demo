# الخطوة 5: الأمان والامتثال

رقم الهاتف المتصل بالذكاء الاصطناعي متصل في الحقيقة **ببطاقتك الائتمانية**. أي شخص يستطيع الوصول إليه يستطيع أن يستهلك رصيدك في OpenAI وTwilio، والوكيل المُهمَل قد يتصل بأشخاص لم يوافقوا قط على التحدث مع ذكاء اصطناعي. تشرح هذه الصفحة ما هو مُدمج في المشروع، وما يجب أن تضيفه أنت.

## الحمايات المُدمجة (مُفعّلة افتراضياً)

| الحماية | ماذا تفعل | الإعداد |
|---|---|---|
| **قائمة السماح للمتصلين** | الأرقام المدرجة فقط تصل إلى الوكيل. أي متصل آخر يتلقى `<Reject>` (رفض) *قبل* الرد على المكالمة: لا تبدأ أي جلسة ذكاء اصطناعي، ولا تُحتسب المكالمة على أنها مُجابة. | `ALLOWED_CALLERS` (افتراضياً يساوي `OWNER_PHONE_NUMBER`؛ إن كان فارغاً = رفض الجميع) |
| **قائمة السماح للأرقام الصادرة** | لا يستطيع وكيلك الاتصال إلا بالأرقام التي أدرجتها، حتى لو طُلب منه (أو خُدع كي) يتصل بشخص آخر. | `ALLOWED_DESTINATIONS` (افتراضياً يساوي `ALLOWED_CALLERS`) |
| **إفصاح إلزامي بأن المتحدث ذكاء اصطناعي** | أول جملة يقولها الوكيل في كل مكالمة تُعلن أنه وكيل ذكاء اصطناعي يعمل نيابةً عنك، ولا يدّعي أبداً أنه إنسان. | `src/persona.js` |
| **التحقق من أصالة طلبات الـ webhook** | الطلبات الواردة إلى `/twilio/voice` يجري فحصها: عبر توقيع Twilio إن كان `TWILIO_AUTH_TOKEN` مضبوطاً، وإلا فبالتأكد من المكالمة عبر واجهة Twilio API. الطلبات المزوّرة تتلقى 403. | تلقائي |
| **رموز بثّ تُستخدم مرة واحدة** | قناة WebSocket للصوت لا تقبل إلا بثاً يحمل رمزاً عشوائياً يُستخدم مرة واحدة، صادراً لتلك المكالمة بعينها، وصالحاً لمدة 3 دقائق. لا يستطيع أحد غيرك فتح جلسات ذكاء اصطناعي على مفتاحك. | تلقائي |
| **واجهة تحكم محلية فقط** | إجراء المكالمات والإجابة عن الأسئلة يتمّان عبر `127.0.0.1:CONTROL_PORT`، وهذا العنوان **لا** يُكشف أبداً عبر ngrok. | `CONTROL_PORT` |
| **حدود التكلفة** | كل مكالمة تُقطع عند `MAX_CALL_SECONDS` (الافتراضي 10 دقائق)؛ وبحدّ أقصى `MAX_CONCURRENT_CALLS` مكالمة في الوقت نفسه. | `.env` |
| **مفتاح API وليس الرمز الرئيسي** | الوصول إلى Twilio يتم بمفتاح API يمكن إلغاؤه. | `TWILIO_API_KEY_*` |
| **الأسرار تبقى محلية** | الملف `.env`، ونصوص المكالمات (`calls/`)، والنسخ الاحتياطية (`data/`) كلها يتجاهلها git. | `.gitignore` |
| **قواعد أمان داخل التعليمات** | يرفض الوكيل كلمات المرور ورموز التحقق OTP وأرقام البطاقات، ولا يوافق أبداً على أي عملية دفع، ويحترم طلب «لا تتصل بي مرة أخرى». | `src/persona.js` |

## الأمان على مستوى رقم الهاتف (مُستحسن بشدة)

قائمة السماح في الخادم لا تعمل إلا ما دام الخادم يعمل والرقم موجّهاً إليه. أضف بوابة ثانية **داخل Twilio** نفسها، كي يُرفض المتصلون المجهولون حتى لو كان خادمك متوقفاً أو إعداداته خاطئة:

**الخيار أ: بوابة Twilio Function (وهي ما يستخدمه صاحب المشروع).** دالة صغيرة في Twilio Function تستقبل كل مكالمة إلى رقمك، فترفض المتصلين المجهولين وتحوّل المتصلين المسموح لهم إلى وكيلك. القالب: [`examples/twilio-gate-function.js`](../../examples/twilio-gate-function.js).

1. Twilio Console ← **Functions and Assets → Services → Create Service** (الدوال والملفات ← الخدمات ← إنشاء خدمة) (مثلاً `inbound-gate`).
2. **Add → Add Function** (إضافة ← إضافة دالة)، بالمسار `/gate`، والصق القالب، واضبط رقمك ورابط وكيلك.
3. **Deploy All** (نشر الكل).
4. Phone Numbers ← رقمك ← «A call comes in» (عند ورود مكالمة) ← **Function** ← خدمتك ← `/gate` ← Save (حفظ).

**الخيار ب: Geo permissions (أذونات الدول).** Voice ← Settings ← **Geo permissions**: فعّل فقط الدول التي تتصل بها. هذا يمنع احتيال المكالمات المدفوعة إلى أرقام مميزة (premium) في الخارج.

**الخيار ج: تنبيهات الإنفاق.** في Twilio: **Admin → Account billing → Usage triggers/alerts** (الإدارة ← فوترة الحساب ← محفّزات/تنبيهات الاستخدام). وفي OpenAI: **Settings → Limits** (الإعدادات ← الحدود) ← تنبيهات الميزانية. أبقِ إعادة الشحن التلقائي مُطفأة ما دمت تجرّب.

## الامتثال: قواعد الطريق للذكاء الاصطناعي الصوتي

القوانين تختلف من دولة إلى أخرى، وهذه ليست استشارة قانونية. لكن هذه العادات تُبقيك في الجانب الآمن في كل مكان تقريباً:

1. **أفصح دائماً عن أن المتحدث ذكاء اصطناعي.** يعرّف الوكيل بنفسه في كل مكالمة بعبارة مثل *«<الاسم>، وكيل الذكاء الاصطناعي الخاص بـ<المالك>»* (وهذا مُدمج في المشروع؛ لا تحذفه). في الولايات المتحدة، تَعُدّ هيئة FCC الأصوات المولّدة بالذكاء الاصطناعي أصواتاً «اصطناعية» بموجب قانون TCPA، ولذلك فإن المكالمات غير المطلوبة بالذكاء الاصطناعي تحتاج إلى **موافقة صريحة مسبقة** من المتلقي.
2. **لا تتصل إلا بمن يتوقع المكالمة.** اتصل بنفسك، أو بفريقك، أو بأشخاص وافقوا على تلقي مكالمات من الذكاء الاصطناعي. لا اتصالات عشوائية بغرباء، ولا حملات تسويقية جماعية، ولا مكالمات آلية (robocalls).
3. **لا تنتحل أي شخصية أبداً.** يجب ألا يتظاهر الوكيل بأنه أنت أو أي شخص حقيقي، ويجب ألا يستنسخ صوت أحد دون موافقته.
4. **التسجيل ونصوص المكالمات.** هذا المشروع **لا** يسجّل الصوت. لكنه يحفظ **نصوص المكالمات المكتوبة** محلياً (`SAVE_TRANSCRIPTS=true`). أماكن كثيرة تُلزمك بإخبار الناس بأن المكالمة تُسجَّل أو تُفرَّغ نصياً؛ اضبط `SAVE_TRANSCRIPTS=false` إن لم تكن بحاجة إليها، واحذف الملفات القديمة في `calls/`.
5. **احترم طلبات التوقف.** إن قال أحدهم «لا تتصل بي مرة أخرى»، يعتذر الوكيل وينهي المكالمة. احذف الرقم من `ALLOWED_DESTINATIONS`.
6. **أوقات الاتصال.** لا تتصل بالناس ليلاً أو في أيام راحتهم.
7. **لا بيانات حساسة.** يرفض الوكيل كلمات المرور ورموز OTP وأرقام البطاقات والهويات. لا تعطه بيانات خاصة لا يحتاجها.
8. **حالات الطوارئ.** الوكيل ليس خدمة طوارئ، ويطلب من الناس إنهاء المكالمة والاتصال برقم الطوارئ المحلي لديهم.

## إذا تسرّب شيء ما

| ما تسرّب | افعل هذا الآن |
|---|---|
| مفتاح OpenAI | platform.openai.com ← API keys ← **Delete** (حذف) ← أنشئ مفتاحاً جديداً |
| سرّ مفتاح Twilio API | Console ← API keys & tokens ← **Delete** (احذف) المفتاح ← أنشئ مفتاحاً جديداً |
| Twilio Auth Token | Console ← API keys & tokens ← **Rotate/Request a secondary token** (تدوير/طلب رمز ثانوي) ← ثم رقِّه ليصبح الرمز الأساسي |
| رمز ngrok | لوحة تحكم ngrok ← Authtokens ← **Reset** (إعادة تعيين) |

ثم راجع صفحات الاستخدام في الموقعين بحثاً عن أي نشاط غير متوقع.
